Cortana eBay Agent Privacy Policy

Who operates it

Ironclad Militaria operates Cortana eBay Agent for internal seller-account testing. The pilot is for the store owner, not for buyers or other sellers.

What the pilot accesses

The initial test uses eBay’s API Explorer to verify authorization for the Ironclad Militaria seller account. It requests the seller-account information returned by eBay’s read-only account lookup. It does not request buyer messages, order details, payment information, or shipping addresses. It does not create, edit, or publish listings.

How test data is handled

The owner signs in on eBay. The app does not ask for the owner’s eBay password. Test responses stay in eBay’s API Explorer for review. Ironclad records only whether the test succeeded, not the full response or token. Ironclad does not sell the test data or use it for advertising. This policy page does not ask visitors to sign in or submit information.

One-draft Windows pilot

The Windows helper sends one photo-free test draft to eBay and checks whether it was accepted. It uses the access token in memory during the run and does not save it. It does not publish the draft, modify existing listings, or request buyer or order information.

How to disconnect or ask a question

The owner can revoke the app’s access in My eBay under Account → Sign in and security → Third-party app access. For privacy questions, contact Ironclad Militaria through its eBay seller profile.

Ironclad will update this policy before expanding beyond the tests described on this page.
